One letter for your day: a tiny deterministic program that writes a single
letter, `Z`, to `/output/entry.txt` — the whole entry for the make.fun bounty
"One Letter for Your Day". Behind the letter sits the word "zombie": a day
spent shuffling through on zero sleep. The output file holds exactly that one
character, no trailing newline, so it passes the gate (UTF-8 text of exactly
1 character).

## Run it

```sh
node main.ts
```
